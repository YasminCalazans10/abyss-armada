# ⚔️ Abyss Armada

**Abyss Armada** é um jogo de batalha naval com temática viking, desenvolvido para navegador utilizando HTML, CSS e JavaScript.

O objetivo é posicionar sua frota e destruir todos os navios adversários antes que sua própria frota seja eliminada.

🎮 **Jogar online:** https://yasmincalazans10.github.io/abyss-armada/

## 🎯 Como jogar

1. Abra o jogo e clique em **Iniciar**.
2. Escolha o nível de dificuldade: **Fácil**, **Médio** ou **Difícil**.
3. Informe os nomes dos jogadores, se desejar.
4. Escolha um dos modos disponíveis:
   - **Iniciar Jogo:** partida entre dois jogadores.
   - **Jogar contra CPU:** enfrente o computador.
   - **Modo Rápido:** os navios são posicionados automaticamente.
5. No posicionamento manual, selecione os navios e escolha onde colocá-los no tabuleiro. Use **Rotacionar** para mudar sua orientação.
6. Após posicionar toda a frota, confirme o posicionamento.
7. Durante a batalha, ataque as posições do tabuleiro adversário tentando encontrar e destruir seus navios.
8. Vence quem destruir toda a frota adversária primeiro.

## 🛡️ Níveis de dificuldade

### Fácil
Tabuleiro 4x4 e uma frota menor, indicado para conhecer o funcionamento do jogo.

### Médio
Tabuleiro 6x6 e uma frota maior, aumentando as possibilidades de posicionamento e ataque.

### Difícil
Tabuleiro 12x12 e uma batalha mais extensa, exigindo mais estratégia para localizar a frota inimiga.

## 🕹️ Modos de jogo

**Dois jogadores:** permite uma partida local entre dois jogadores, cada um posicionando sua própria frota.

**Contra CPU:** o jogador posiciona seus navios e enfrenta uma inteligência controlada pelo jogo.

**Modo Rápido:** realiza o posicionamento automático das frotas para iniciar a batalha mais rapidamente.

## 🔊 Sons e efeitos

O jogo possui trilha sonora e efeitos de áudio para introdução, ataques, explosões e outros momentos da batalha. Por segurança, navegadores podem bloquear reprodução automática de áudio. Caso a música não comece imediatamente, clique ou interaja com a página uma vez.

## 💻 Tecnologias utilizadas

- **HTML5:** estrutura das telas e elementos do jogo.
- **CSS3:** aparência, organização dos tabuleiros, animações e interface visual.
- **JavaScript:** regras do jogo, posicionamento dos navios, turnos, pontuação, ataques, CPU, efeitos e controle dos áudios.
- **GitHub Pages:** publicação da versão online do jogo.

## 🚀 Como executar após baixar o projeto

O Abyss Armada não precisa de instalação de dependências ou `npm`.

1. Baixe ou clone o repositório.
2. Mantenha a estrutura das pastas `imagens` e `sons` sem alterar seus nomes.
3. Abra o arquivo **`index.html`** em um navegador moderno.
4. Clique na página para permitir a reprodução dos sons caso o navegador bloqueie o áudio automaticamente.

Também é possível executar o projeto pelo **Visual Studio Code** utilizando uma extensão de servidor local, como Live Server.
